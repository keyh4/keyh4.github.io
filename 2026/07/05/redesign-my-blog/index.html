为什么我要重新设计这个博客

2026.07.05designblog

一个好的个人博客应该是什么样子？这个问题我思考了很久。

大多数人选择现成的主题，调整一下颜色和字体就算完事。这没什么不对——把时间花在内容上确实更重要。但对我而言，博客本身就是一件值得精心建造的作品。

从”修修补补”到”推倒重来”

最初的计划很简单：在 Hexo + Fluid 主题的基础上，改改 CSS 就完了。我确实这么做了——写了 500 多行自定义样式，调整配色、优化排版、添加动效。看起来还不错。

但问题是：骨架没变。

Fluid 的 Bootstrap 栅格系统、Material Design 阴影、圆角卡片、居中布局——这些东西像一个隐形的牢笼。再怎么在表面涂装，底层结构决定了整体的性格。我想要的是一个更锋利、更有个性的东西。

所以我推倒重来。

暴露结构的建筑美学

新设计的核心理念很简单：把构造暴露出来。

页面背景上可以看到淡淡的网格线——这不是装饰图案，而是真实的比例网格系统。12 列、21px 间距、55px 边距——所有元素都落在这个精确的网格上。

四角的十字标记像工程图纸上的定位符号，提醒着这个页面是被”建造”出来的。

整站的布局、间距、字号都基于一个统一的比例常数（1.272，Klein 比例），让所有东西在数学上相互关联。你不会注意到这些数字，但你会感觉到和谐。

建造本身就是表达

写文章是表达，建造这个博客也是表达。每一行 CSS、每一个网格计算，都是在说：这是我做东西的方式。

这个博客会持续进化。不是因为它不够好，而是因为建造本身就是最好的学习方式。
